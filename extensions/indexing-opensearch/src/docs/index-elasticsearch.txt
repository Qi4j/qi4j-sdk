[[extension-index-opensearch,OpenSearch Index/Query]]
= OpenSearch Index/Query =


[devstatus]
--------------
source=extensions/indexing-opensearch/dev-status.xml
--------------


Index/Query services backed by https://github.com/opensearch-project[OpenSearch] search engine built on top of
http://lucene.apache.org/[Apache Lucene].

WARNING: OpenSearch Index/Query do not support ComplexQueries from the Query API, ie. queries by "example value".

Two modes of operation are supported:

- managed cluster client ;
- with a provided OpenSearchClient.

In any case, Lucene hard limits apply.
See the https://lucene.apache.org/core/9_12_2/core/org/apache/lucene/codecs/package-summary.html[Lucene File Format]
documentation about maximum index size and document count.
Moreover, each field cannot be larger than 32766 bytes in its serialized form.
